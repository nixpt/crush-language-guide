# schemas/

`notebook.schema.json` is crush-notebook's `.crush-nb` document schema, copied
unchanged from [nixpt/crush-notebook](https://github.com/nixpt/crush-notebook)
`schemas/notebook.schema.json` at commit `6b1a56a` (v0.1.0; identical at v0.1.1).
`scripts/build-notebooks.py --validate schemas/notebook.schema.json` checks every
generated chapter notebook against it. Refresh it by copying a newer version.
